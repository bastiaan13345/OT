R2 media storage

Audio, artwork, avatars, and explicit downloadable files. The database and private application logic stay on your PC.

Shared Apple modules

OpenTunesCore owns models and errors; OpenTunesAPI owns URLSession and token refresh; OpenTunesAuth owns account state and Keychain access; OpenTunesPlayback owns AVPlayer queue, Now Playing, remote commands, and downloads; feature modules own Home, Browse, Library, Feed, Social, and account UI. Platform shells only compose navigation and platform adapters.

Intentional boundaries

  • No React Server Action protocol in native clients
  • No raw Prisma records or internal media locators in API responses
  • No database or R2 credentials in Apple apps
  • SwiftUI owns playback state; AppKit owns only NSPanel lifecycle

Known availability boundary

  • If the PC is offline, new API activity and social state stop
  • Previously permitted downloads and cached metadata still work
  • R2 media alone cannot replace unavailable catalog/auth APIs
